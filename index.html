LESSON 1 · PYTHON BASICS

Your first steps with Python

Learn what Python is, display messages, and store information in variables. Read each short explanation, then try the code.

What is Python?

Python is a popular programming language. A programming language lets you give a computer instructions in a structured way. Python is known for readable code, which makes it a friendly language for beginners.

What can you use it for?

People use Python to build websites, automate repetitive tasks, analyse data, create scientific tools and explore artificial intelligence. The same basic skills can be used in many different projects.

Display output with print()

The print() function displays information. Text needs quotation marks; this kind of text value is called a string. 

print("Hello, Python!")
print("I am learning to code.")

Store values in variables

A variable is a name that refers to a value. The equals sign (=) assigns a value to that name. 

learner_name = "Amina"
lessons_completed = 1

Strings and numbers

Text inside quotes is a string. Whole numbers such as 7 are integers; numbers with a decimal point such as 3.5 are floating-point numbers. Numbers do not need quotation marks. 

greeting = "Hello"
age = 20
temperature = 24.5
print(greeting, age, temperature)

Run a simple program

A program is a set of instructions. Python normally runs those instructions from top to bottom. Try changing the values and running your own version in the playground below. 

name = "Amina"
favorite_number = 7

print("Hello,", name)
print("Your favorite number is", favorite_number)

LESSON 2 · PYTHON OPERATORS

Do calculations with Python

Operators are symbols that tell Python what calculation to perform. Try these examples in your playground.

Addition and subtraction

Use + to add and - to subtract. These operators work with numbers. 

print(8 + 5)  # 13
print(8 - 5)  # 3

Multiplication and division

Use * for multiplication and / for division. Division with / can produce a decimal result. 

print(4 * 3)  # 12
print(8 / 2)  # 4.0

Floor division and remainder

// gives the whole-number part of a division. % gives the remainder left over. 

print(17 // 5)  # 3
print(17 % 5)   # 2

Powers and calculation order

Use ** to raise a number to a power. Python follows normal calculation order; parentheses let you group a calculation first. 

print(2 ** 3)       # 8
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20

LESSON 3 · MAKING DECISIONS

Make choices with if

Programs can choose what to do based on information. Python uses comparisons and conditional statements to make those decisions.

Compare values

A comparison checks how two values relate. It produces a Boolean value: either True or False. 

print(8 > 5)   # True
print(8 == 5)  # False
print(8 != 5)  # True

Comparison operators

Use == to check equality, != for “not equal”, and < or > for less than or greater than. <= and >= include equality. 

score = 75
print(score >= 50)  # True

Choose with if and else

An if statement runs its indented block only when its condition is true. else provides a different path when the condition is false. The colon and indentation are important in Python. 

age = 16

if age >= 18:
    print("You are an adult.")
else:
    print("You are not an adult yet.")

Check several possibilities with elif

Use elif (short for “else if”) to test another condition when the earlier one was false. Python checks the conditions from top to bottom and runs the first matching block. 

score = 82

if score >= 90:
    print("Excellent")
elif score >= 50:
    print("You passed")
else:
    print("Keep practising")

Combine conditions

Use and when both conditions must be true, or when either can be true, and not to reverse a true/false value. 

age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("You can enter.")

LESSON 4 · PYTHON LOOPS

Repeat work with loops

A loop repeats a block of instructions. Loops help you avoid copying the same code again and again.

Repeat a known number of times

A for loop visits each item in a sequence. Use range() when you want to repeat a task a number of times. 

for number in range(3):
    print("Hello!")

This prints three greetings. The loop variable number takes the values 0, 1, and 2.

Understand range()

range(stop) starts at zero and stops before the stop value. You can also give it a start and stop value. 

for number in range(1, 4):
    print(number)

# Prints 1, 2, and 3

Repeat while a condition is true

A while loop repeats while its condition is True. Change something in the loop so the condition eventually becomes false; otherwise the loop may run forever. 

count = 1

while count <= 3:
    print(count)
    count = count + 1

Indentation marks the loop body

Python uses indentation to show which instructions belong to a loop. The indented instructions are repeated each time through the loop. 

for number in range(1, 4):
    square = number * number
    print(square)

Choose the right loop

Use a for loop when you are working through a sequence or know how many repetitions you need. Use a while loop when you want to continue until a condition changes. 

for day in range(1, 4):
    print("Practice day", day)

LESSON 5 · PYTHON COLLECTIONS

Store groups of information

Collections let you keep related values together. Start with lists for ordered items and dictionaries for information labelled with keys.

Create a list

A list stores multiple values in order. Write its items inside square brackets and separate them with commas. 

fruits = ["mango", "banana", "orange"]
print(fruits)

Read an item by its index

List positions are called indexes. Python starts counting indexes at zero, so the first item is at index 0. 

fruits = ["mango", "banana", "orange"]
print(fruits[0])  # mango
print(fruits[1])  # banana

Add and change list items

Use append() to add an item at the end. Assign a new value at an index to change an item. 

fruits = ["mango", "banana"]
fruits.append("orange")
fruits[0] = "pineapple"
print(fruits)

Find how many items

The len() function returns the number of items in a list. A for loop can visit each item in order. 

fruits = ["mango", "banana", "orange"]
print(len(fruits))

for fruit in fruits:
    print(fruit)

Use a dictionary for labelled information

A dictionary stores values under descriptive keys. Use curly braces with a key: value pair, then look up a value by its key. 

learner = {
    "name": "Amina",
    "level": 1
}

print(learner["name"])
learner["level"] = 2

LESSON 6 · PYTHON FUNCTIONS

Organise code with functions

A function is a reusable block of code. Give it a name, provide information when needed, and call it whenever you want it to do its job.

Define and call a function

The def keyword defines a function. Indented lines are its body. Defining it does not run it; call it by writing its name followed by parentheses. 

def greet():
    print("Hello, learner!")

greet()

Pass information with parameters

A parameter is a name in a function definition. An argument is the value supplied when calling that function. 

def greet(name):
    print("Hello,", name)

greet("Amina")

Return a result

return sends a result back to the code that called the function. You can save that result in a variable or use it in another calculation. 

def add_numbers(first, second):
    return first + second

answer = add_numbers(8, 5)
print(answer)

Use a default parameter

A default value is used when a function call does not provide that argument. Arguments without defaults must come before parameters with defaults. 

def greet(name="friend"):
    print("Hello,", name)

greet()
greet("Amina")

LESSON 7 · WORKING WITH STRINGS

Work with text in Python

A string is text inside quotes. Python gives you useful tools to combine, inspect, format, and find parts of strings.

Combine strings

Use + to join strings together. Add a space yourself when you want words separated. 

first_name = "Amina"
greeting = "Hello, " + first_name
print(greeting)

Find a string's length

len() counts the characters in a string, including spaces and punctuation. 

message = "Hello!"
print(len(message))  # 6

Change letter case

String methods such as upper(), lower(), and title() return a changed version of the text. 

course = "learn python"
print(course.upper())
print(course.title())

Use an f-string

An f-string lets you put a variable or expression inside a string. Start the string with f and put the value in curly braces. 

name = "Amina"
lessons = 7
print(f"{name} has studied {lessons} lessons.")

Select characters and slices

Strings use zero-based indexes like lists. A slice selects a range of characters; its ending index is not included. 

language = "Python"
print(language[0])     # P
print(language[0:3])   # Pyt

LESSON 8 · ERRORS AND EXCEPTIONS

Handle errors helpfully

Errors are part of programming. Learn to read the error message and handle expected problems so your program can respond clearly.

Read the error message

A syntax error means Python cannot understand the code's structure. A runtime error happens while the program is running. Read the last line and the line number to start debugging. 

print("Hello"  # Missing a closing )

Catch an expected error

Put risky code in a try block and handle a specific exception in except. Catching a specific error gives a more useful response. 

try:
    number = int("hello")
except ValueError:
    print("Please enter a whole number.")

Use else and finally

The optional else block runs when no exception happened. finally runs whether the operation succeeded or failed. 

try:
    number = int("12")
except ValueError:
    print("That was not a number.")
else:
    print("You entered", number)
finally:
    print("Finished checking.")

Debug one small step at a time

Reproduce the problem, read the traceback, check the named line and values, then make one change and test again. The playground displays Python error messages below the editor. 

age_text = "twenty"
age = int(age_text)  # ValueError

LESSON 9 · PYTHON FILES

Read and write files

Programs can save and load text. Use a context manager with with open(...) so Python closes a file when the block ends, even if a problem occurs.

Open a file for writing

The "w" mode writes a file and replaces its old contents. write() stores text. 

with open("notes.txt", "w") as file:
    file.write("Python is fun!")

Read a file

Use "r" to read text from an existing file. The read() method returns the contents. 

with open("notes.txt", "r") as file:
    contents = file.read()

print(contents)

Add to a file

The "a" mode appends text to the end of a file instead of replacing its existing contents. Add "\n" when you want a new line. 

with open("notes.txt", "a") as file:
    file.write("\nKeep practising!")

Use a safe file pattern

Keep file access inside a with block. Catch FileNotFoundError if a file might not exist yet. Avoid opening files you do not recognise. 

try:
    with open("notes.txt", "r") as file:
        print(file.read())
except FileNotFoundError:
    print("The notes file does not exist yet.")

Where this playground stores files

In this lesson the code runs in Pyodide's temporary browser-based file system. The example creates and reads notes.txt there; it does not upload the file to a server, and the temporary file may disappear when the page is refreshed. 

with open("notes.txt", "w") as file:
    file.write("My first Python file")

with open("notes.txt", "r") as file:
    print(file.read())

LESSON 10 · OBJECT-ORIENTED PYTHON

Build your own objects

Object-oriented programming groups related data and behaviour together. A class describes a kind of object; an object is one instance created from that class.

Define a class

A class is a blueprint for creating objects. By convention, class names use CapWords. 

class Learner:
    pass

Create an object with __init__

The __init__ method sets up a new object. self refers to that particular object. 

class Learner:
    def __init__(self, name):
        self.name = name

learner = Learner("Amina")
print(learner.name)

Store an object's attributes

An attribute is data stored on an object. Different objects created from one class can store different attribute values. 

learner_one = Learner("Amina")
learner_two = Learner("Brian")

print(learner_one.name)
print(learner_two.name)

Add behaviour with methods

A method is a function defined inside a class. It can use self to work with that object's attributes. 

class Learner:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello,", self.name)

Learner("Amina").greet()

Keep data and behaviour together

An object combines state (its attributes) and behaviour (its methods). This can make related program logic easier to organise as a project grows. 

class Counter:
    def __init__(self):
        self.value = 0

    def add_one(self):
        self.value = self.value + 1

counter = Counter()
counter.add_one()
print(counter.value)
